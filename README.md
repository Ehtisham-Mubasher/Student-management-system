## 📌 Open Ended Lab (OEL) Project | SEC6402_SCD

A comprehensive desktop application for managing hospital operations including patient registration, doctor management, appointment scheduling, and billing. Developed as part of **Software Construction & Development** course requirements.

### 🚀 Application Features

#### Patient Management
- ➕ Register new patients with complete medical history
- 📋 View all patients with search functionality
- ✏️ Update patient information
- 🗑️ Soft delete patient records
- 🔍 Search patients by name or phone number

#### Doctor Management
- 👨‍⚕️ Add/Edit doctor profiles
- 💰 Manage consultation fees
- 📊 Track experience and qualifications
- ✅ Monitor doctor availability status

#### Appointment System
- 📅 Book appointments with preferred doctors
- 🏥 Track appointment status (Scheduled/Completed/Cancelled)
- 📝 Maintain medical records and prescriptions
- 📋 View appointment history

#### Billing System
- 💵 Generate invoices for consultations
- 💳 Track payment status (Pending/Partial/Paid)
- 🧾 Add medicine, lab, and other charges
- 📊 Generate financial reports
